关键约束提醒

AutoHotkey v2 原生 GUI 的限制：
• 不支持 CSS backdrop-filter（毛玻璃效果需用纯色模拟）
• ListView 不支持行内按钮/链接（操作列只能用外部按钮）
• 动态显示/隐藏控件需要手动管理位置
• 卡片式布局需用 GroupBox + 多个控件模拟
• 侧栏布局需两个区域分别管理控件
