- **涉及文件**：`asd-tauri/src-tauri/ahk_executor/ipc_client.ahk`（`:69` `:100` `:129-134`）

- **验证是否真修好**（阳性对照）：临时脚本内**复刻旧逻辑**与**新逻辑**同跑同一组脏键名，输出交给 Python `json.loads` 严格校验：

### #4 🟠 watchdog 优雅关机 Phase 3 持锁执行无超时 `wait()`

- **根因**：`graceful_shutdown_watchdog` 在持有 watchdog 锁的情况下调用 `kill_and_reap()`，其内部 `Child::wait()` 是 `WaitForSingleObject` 且**无超时**。与本函数自己的文档（「锁内仅做状态快照，轮询在锁外执行」）直接矛盾。
- **影响范围**：子进程不退出时，当前 tokio 工作线程被无限期阻塞且锁不释放 → `WatchdogRunner::run`、状态同步循环、`get_executor_status` / `reset_watchdog` 全部挂起，UI 冻结。
- **涉及文件**：`asd-tauri/src-tauri/src/infrastructure/watchdog.rs`（`:558-563`、新增常量 `KILL_REAP_TIMEOUT` / `KILL_REAP_POLL_MS`）
- **修复**：短暂加锁**取走** `child` → 锁外 `kill()` + 有界轮询 `try_wait()`（上限 3s，超界只告警）→ 再短暂加锁 `cleanup()`。
- **是否真存在**：✅ 源码确认（`:559-560` 持锁 + `kill_and_reap` 内 `:204` 无超时 `wait()`）。
- **验证**：watchdog 集成测试 `test_watchdog_graceful_shutdown` 等 **15/15 通过**（已解禁，见 #22）。

### #27 🟢 便携模式命令注入面

- **根因**：`.bat` 走 `cmd /C <path>`，Windows 对含空格且带引号的参数有引号剥离行为。
- **涉及文件**：`asd-tauri/src-tauri/src/infrastructure/watchdog.rs`（`:284-288`）
- **修复**：改为 `cmd /D /S /C "<path>"` —— `/D` 跳过 AutoRun，`/S` 按最外层引号原样取用、不再二次解析；注释标明不接受外部输入。
- **注意**：**不能**直接 `Command::new(exe_path)`，CreateProcess 无法执行 `.bat`。
- **验证**：先 grep 确认无测试断言该分支的 program/args，改后编译通过。

### #19 🟡 `send()` 持锁做 I/O —— 刻意只改注释，不改行为

- **根因**：`send()` 持有 `send_half` 锁完成 `write_all`(2s) + `flush`(2s)，最坏 4s。
- **判断**：结构性修复（单写者任务 + mpsc）属重构；而「调小 `SEND_TIMEOUT`」的省事改法会在 AHK 偶发繁忙时制造**误超时 → 误判管道不可靠 → 不必要的断连重连**，等于用一个新的间歇性故障换掉一个理论上的最坏时延。按「避免引入新问题」原则，**本次只纠正与实现不符的注释**。
- **修复**：`bridge.rs` 原注释「临界区极短（仅 `lock().await` + `send_command().await`）」与 4s 上界不符 → 改写为真实上界 + 为什么仍可接受 + 为什么不做省事改法。
- **遗留**：登记 **TD-066**（DPI 3.19 / P2 / 到期复查 2026-12-18）。

## 三、本轮踩到的坑（值得记住）

1. **`tests/test_ahk_executor/*.ahk` 不能单独运行** —— 它们只定义套件类、没有启动代码，单独跑是**空转且退出码 0**，极易误判为「已验证」。必须跑 `tests/run_all_tests.ahk`（它 `#Include` 了这 5 个文件）。
2. **`tests/test_results.log` 会被复用** —— 跑之前先 `rm`，否则可能把旧日志当成当次结果（我第一次就差点误认）。
3. **改完 Rust 必须跑 `cargo fmt` + `clippy`**，不能只跑 `cargo test`：fmt 改掉了我手写的换行；clippy 报了文档注释裸标识符 missing_backticks 与 `Err(_)` 的 match_wild_err_arm。
4. **`.bat` 不能用 `Command::new` 直接执行** —— CreateProcess 不支持，仍需 cmd；加固只能靠 `/D /S /C "..."`。
5. Bash 命令里出现 `cmd /C` 字面串会被安全策略拦截，需用文件读取工具代替。
