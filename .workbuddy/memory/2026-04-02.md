# 2026-04-02

## 修复 asd.ahk 语法错误: Missing "}" at line 1359

### 根因
AHK v2 中 `try { ... }` 的 OTB (One True Brace) 风格在函数/方法内部会导致 "Missing }" 语法错误。`try` 后的花括号 `{` 必须在下一行。

### 修复内容 (asd.ahk)
1. **Line 1351**: `try { SendEvent(...) }` → 展开为多行 `try {` + `SendEvent(...)` + `}`
2. **Line 1368**: 同上
3. **Line 1375**: `try { SendEvent(...) }` → 展开为多行
4. **Line 481**: `_ReleaseKey` 中 `catch` 块内的 `continue` 不在循环中，已删除
5. **Line 1990, 1995**: `catch bindErr` / `catch rollbackErr` 缺少 `as` 关键字，改为 `catch as bindErr` / `catch as rollbackErr`

### AHK v2 关键规则
- `try { }` 不能在函数内部使用单行 OTB 风格，必须多行
- `catch` 变量必须用 `as` 关键字: `catch as err`，不能直接 `catch err`
- `continue` 只能在 Loop/For 内使用
- `/ErrorStdOut` 可以捕获 AHK v2 的语法错误到 stderr
