## TD-045 批次 5：needless_pass_by_value（11 项）—— 修 1 项、豁免 10 项

### ⚠️⚠️ 本轮最重要的教训：别把推断当结论写进注释

我最初的判断是「`&str` 参数编译能过、运行时必炸（from_value 借不出数据）」，
**实测证明是错的**：

- 实测：把 `get_group_detail(group_id: String)` 改成 `&str` → **编译通过**。
- 查 Tauri 源码 `ipc/command.rs`：`CommandArg` 的 `from_command` 走
  `command.deserialize_json()` 拿 `&'de serde_json::Value`，再用 `pass!` 宏转发给
  `&Value` 的 Deserializer。而 serde_json 为 `&'de Value` 实现的 Deserializer
  **支持 `visit_borrowed_str`**。
- 探针实测：`<&str as Deserialize>::deserialize(&Value)` → `Ok("F1")`。
- 反例：`&[String]` / `&Config` 在 serde 里**根本没有** `Deserialize` 实现，改了编译不过。
  （clippy 那句 "consider `&[String]`" 它自己也给不出。）

**所以豁免三类的真实理由分别是**：① `state: tauri::State<..>` 必须按值（Tauri 按类型
提取）；②③ `&Config` / `&[String]` 没有 Deserialize 实现；④ `group_id: String`
技术上可改 `&str`，但那是**改对外 IPC 契约**，而 E2E 覆盖不全（TD-016）。

**已把写错的那版注释改掉** —— 误导性注释比没注释更糟（台账里「误导性文档」是硬性 P0）。

### 豁免放模块头，不放 Cargo.toml

放 `src/commands/{config,group,system}_cmd.rs` 的**模块头** `#![allow(...)]`，
Cargo.toml 里那行 allow 直接删掉。区别：后者会让 lint 对整个 crate 失效，
前者只豁免 command 模块 —— **本轮唯一那个真问题（`set_state` 的多余 `.clone()`）
正是 lint 在非 command 代码里报出来的**。

### 防复发：静态扫描代替编译期

模块头 allow 之后编译期没保护了，补 `tests/command_contract_tests.rs::
tauri_command_args_stay_owned`：扫 5 个 command 文件，`#[tauri::command]` 的
参数除 `state` 外不得是 `&` 开头。带锚点 `checked > 0`（否则解析器失效就退化成
「空集通过」的永真式）。阳性对照：改 `group_id: &str` → 报出精确参数名。

## 顺带修掉一个「守护本身有缺陷」的问题（G3c 变红）

批次 5 给三个 command 模块加文件头注释时写了 `#[tauri::command]` 这个字面量，
结果 **G3c（JS 单测）变红**。查下来不是我注释写错了，是守护自己的缺陷：

`src/__tests__/api_contract.test.js` 的 `rustCommands()` 用裸的
`/#\[tauri::command\]/g` 搜索，**命中注释里的散文后取「后面第一个 fn」**，
于是抽出 6 个**幻影命令**（`get_config_impl`、`get_groups_impl`、
`get_executor_status_impl`、`extract_command_params`、`tauri_command_args_stay_owned` ×2），
「Rust 注册的命令都被前端用到」直接失败。

修法两条，第二条才是关键：
1. 正则改**整行锚定** `^[ \t]*#\[tauri::command\][ \t]*$`（属性独占一行；注释以 `///` 开头）
2. 补断言「**抽出的命令必须都在 lib.rs 的 generate_handler 注册块里**」+ 锚点
   「注册块应解析出 >=30 个命令」。光改正则只是修好这一次，这条断言才能让
   以后任何形式的幻影都立刻现形。阳性对照：改回裸正则 → 2 条红。

**教训（可复用）**：写「扫描源码 + 正则」型的静态守卫时，**必须**断言
「抽出的东西属于某个权威集合」，否则解析器一旦匹配到注释/字符串，
守卫就会用假数据去比对 —— 而且假数据往往让断言**通过**（空集对空集或全量对全量），
比报错更危险。

### TD-051：e2e 进图 + JS 环检测 + extra_exclude 守护（commit `5115556`）

`build_js()` 原用 `extra_exclude=("asd-tauri/e2e/",)` 把 **19 个 `.js` 整体排除**，
