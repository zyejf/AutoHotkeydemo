# ASD 技能管理器 · 用户手册

本手册面向**终端用户**（即「我装了，怎么用」），不面向二次开发者。所有功能描述仅依赖**你在 UI 里能看到的按钮与文字**，不要求你知道 IPC、Rust、AutoHotkey 等内部细节。

> 排障类问题（如装不上、热键失效、配置丢失）请直接看 [`troubleshooting.md`](./troubleshooting.md)；本文聚焦**正常路径下的使用**。

## 1. 安装与首次启动

### 1.1 安装

双击从仓库 [Releases](../../releases) 页面下载到的安装包（`.msi` 或 NSIS `.exe`）。安装器会以**当前用户**模式安装（不需要管理员），默认装到 `%LOCALAPPDATA%\Programs\ASD - 技能管理器\`。

**第一次安装时，安装器会下载 WebView2 运行时**（约 80 MB），这是 Windows 系统自带 Edge 浏览器所用的渲染组件 —— 本应用的前端依赖它。下载完成后会自动开始安装本应用。

> ⚠️ **如果当前电脑无法联网**：请提前从其他机器下载 [WebView2 Standalone Installer](https://developer.microsoft.com/microsoft-edge/webview2/) 并安装一次，之后再装本应用即可。详见 [`troubleshooting.md`](./troubleshooting.md) §1。

### 1.2 首次启动

安装完成后，桌面会出现「ASD - 技能管理器」图标。双击启动 ≈ 2-3 秒内主窗口出现，状态栏左下角的圆点为**绿色「就绪」**即表示一切正常。

首次启动时**不会自动创建任何分组**，仪表盘会是空列表（只有「+ 添加新分组」按钮）。

## 2. 界面导览

主窗口分为三个区域：

![主界面布局示意](./func_test/01_dashboard_initial.png)

### 2.1 左侧导航栏

6 个主页面入口，从上到下：

| 入口 | 用途 | 何时打开 |
|---|---|---|
| **仪表盘** | 看所有分组、批量启停 | 默认首页 |
| **分组编辑** | 增删改单个分组 | 配置具体连招 |
| **全局设置** | 改主题、控制热键、长按参数 | 调整全局行为 |
| **调试监控** | 实时日志、性能图、执行器状态 | 出问题时排障 |
| **备份管理** | 创建 / 恢复 / 删除配置快照 | 大改前后 |
| **按键测试** | 录制按键与验证连招 | 不知道「该按哪个键」时 |

> ⚠️ 应用还有一个**诊断信息**页（在导航栏最下方、调试监控之下），用于显示版本、日志目录、执行器状态等排障信息，以及一键**重置看门狗**按钮。**它是排障专用入口**，不在常规使用流程里 —— 详见 [`troubleshooting.md`](./troubleshooting.md) §2。

### 2.2 右上控制条（始终可见）

无论你在哪个页面，右上角永远有这三个按钮：

- **紧急停止**（默认 `F12`）：按下立即释放所有被脚本按住 / 触发的键，**不管当前在哪个分组**。这是「救命键」，出问题先按它。
- **全局开关**（默认 `Ctrl+1`）：一键暂停 / 恢复所有分组的运行。
- **热重载**：从磁盘重新读取 `config.json` 并刷新 UI，不重启应用。当你在两个窗口同时编辑配置时很有用。

### 2.3 状态栏底部

左侧的绿 / 黄 / 红圆点反映**执行器（AutoHotkey 子进程）状态**：

- **绿点（就绪）**：正常
- **黄点（启动中 / 重启中）**：过渡状态，等 3-5 秒
- **红点（失败）**：子进程崩了或卡死，去「诊断信息」页看具体错误并点「重置看门狗」（详见 [`troubleshooting.md`](./troubleshooting.md) §2.4）

## 3. 创建与管理分组

**「分组」** 是本应用的核心单位：一个分组 = 一个连招 / 一组联动操作。每个分组有独立的 ID、名称、触发热键、执行模式、按键序列。

### 3.1 从模板快速创建

进「分组编辑」页，顶部「快捷模板」一行五个按钮：

| 模板按钮 | 适用场景 |
|---|---|
| **周期按键** | 持续按一个键（如按住开火） |
| **序列按键** | 按固定顺序按多个键（如一套连招） |
| **长按保持** | 按下热键后持续按住某个键，松开热键释放 |
| **增强周期** | 周期按键，但带防抖、错峰间隔、轮询恢复等高级参数 |
| **增强序列** | 序列按键，但每步可独立配置延迟 |

点击任意模板，会自动填入该模式所需的字段，然后你只需改 ID / 名称 / 热键 / 按键。

### 3.2 手动创建

不使用模板也可以：

1. 进「分组编辑」 → 顶部按钮组下方有「基本信息」区，填 ID、名称、热键。
2. 在「执行模式」区选模式（详见 §4）。
3. 滚到底部「按键配置」区，按提示填具体按键与间隔 / 延迟。
4. 点底部 **保存**（`Ctrl+S` 也行）。

### 3.3 编辑、克隆、删除

仪表盘每个分组卡片右下有四个按钮：

- **启动 / 停止**：启停该分组（绿色高亮 = 运行中）
- **编辑**：跳到编辑页
- **克隆**：复制出一个新分组（ID 自动加 `_copy` 后缀，名称加「(副本)」），常用于基于现有配置微调
- **删除**：删除分组，**不可撤销**（但配置每 5 分钟自动备份一次，可从「备份管理」恢复，见 §8）

![仪表盘分组卡片](./func_test/08_dashboard_multiselect_result.png)

### 3.4 多选与批量操作

仪表盘右上角有 **「多选模式」** 按钮。打开后每个分组卡片左侧出现复选框，可多选后：

- **批量启动 / 停止**：一键启停多个
- **批量删除**：删除多个（同样会进备份）

## 4. 10 种执行模式速查

| 模式 | 名字 | 适用 | 关键参数 |
|---|---|---|---|
| `periodic` | 周期性 | 持续按一个键 / 多个键循环 | 按键列表、按键时长 ms、间隔 ms |
| `sequence` | 序列 | 按固定顺序触发多键 | 按键列表、每个键的延迟 ms |
| `hybrid` | 混合 | 同时跑周期性 + 序列 | 同上，分两套字段 |
| `hold` | 长按 | 按住热键期间持续按住目标键 | 按键列表 |
| `enhanced_periodic` | 增强周期 | 周期性 + 防抖 / 错峰 / 轮询恢复 | 同上 + 防抖延迟、轮询间隔、按键速率 |
| `enhanced_sequence` | 增强序列 | 序列 + 每步独立延迟配置 | 按键列表 + 每步延迟数组 |
| `enhanced_hybrid` | 增强混合 | 同时跑增强周期 + 增强序列 | 同上 |
| `joystick_periodic` | 手柄周期 | 手柄周期性按键（**需要 vJoy**） | 手柄按键列表、间隔 |
| `joystick_sequence` | 手柄序列 | 手柄按键按顺序触发（**需要 vJoy**） | 手柄按键列表 + 每步延迟 |
| `joystick_hold` | 手柄长按 | 手柄持续按住（**需要 vJoy**） | 手柄按键列表 |

**快捷模板区只有前 5 个模板按钮**（周期 / 序列 / 长按 / 增强周期 / 增强序列）；手柄模式与增强混合需要在「执行模式」区域**手动选择**。

> ⚠️ **手柄模式需要先安装 [vJoy 驱动](https://sourceforge.net/projects/vjoystick/)**，否则按键发不出去。安装一次后 Windows 重启生效。

## 5. 录制按键（按键测试页）

如果不知道「我那个键的内部名字是什么」，用「按键测试」页录：

![按键测试 - 录制模式](./func_test/06_keytest_page.png)

1. 进「按键测试」 → 默认就是 **录制模式**（紫色「录制」按钮亮）。
2. 选「导出模式」：
   - **周期性**：录一组键，自动导出为周期按键模式可用的按键列表。
   - **序列**：同上，序列模式。
3. 点 **「开始录制」** → 按你想录的键 → 点 **「停止录制」** → 在下方文本框得到按键名列表。
4. 复制列表，去分组编辑页贴到对应字段。

> 录制的按键名是 AHK 内部名（如 `Space`、`a`、`LButton`、`^1` 表示 `Ctrl+1`、`+a` 表示 `Shift+a`、`!F4` 表示 `Alt+F4`）。

### 5.1 验证模式

「按键测试」页还有一个 **「验证」** 标签页，用于「我的连招实际按出来对不对」：

![按键测试 - 验证模式](./func_test/15_keytest_verify.png)

1. 切到「验证」标签 → 选你要验证的分组 → 点 **「开始验证」**。
2. 按下该分组的触发热键，应用会记录实际发出的按键序列。
3. 再点 **「停止验证」**，下方显示验证历史。

## 6. 绑定与修改热键

每个分组有**一个**触发热键（在「分组编辑」页基本信息区）。全局还有 5 个**控制热键**（在「全局设置」页改）。

### 6.1 设置分组的触发热键

![热键捕获示例](./func_test/12_settings_hotkey_change.png)

1. 进「分组编辑」 → 找到 **热键** 输入框。
2. 点输入框（变紫色边框表示进入捕获态）。
3. 直接按你想要的组合键：`F1` / `Ctrl+Q` / `Alt+1` / `^!r`（AHK 语法）等都可。
4. 输入框内会显示**键名文本**（如 `F1` / `^q` / `!1`），不是「我按了什么事件」。
5. 保存即生效。

> **同一热键只能绑给一个分组**。如果你给新分组绑了一个已经在用的热键，保存时会提示冲突，旧分组的该热键会被清空。

### 6.2 修改全局控制热键

进「全局设置」→「控制热键」区，可见 5 项：

| 项 | 默认 | 用途 |
|---|---|---|
| 紧急停止 | `F12` | 释放所有按键 |
| 全局开关 | `Ctrl+1` | 一键暂停 / 恢复所有分组 |
| 显示状态 | `Ctrl+0` | 临时显示仪表盘当前状态悬浮窗 |
| 长按开关 | `Ctrl+h` | 切换「长按模式」开关 |
| 释放长按 | `Ctrl+r` | 仅释放长按模式按住的键 |

改法和分组热键一样：点输入框 → 按下组合键 → 输入框显示键名 → **自动保存**（不用点保存按钮）。

## 7. 全局开关、紧急停止、热重载

这三个始终在主窗口右上角：

- **紧急停止**（默认 `F12`）：**救命键**。按一下，立即调用 AHK 子进程的「释放所有键」指令，**不依赖应用 UI 是否响应**。在游戏里「按键卡住松不开」时按它。
- **全局开关**（默认 `Ctrl+1`）：把所有正在运行的分组暂停；再按一次恢复。比紧急停止温和。
- **热重载**：从磁盘重新读 `config.json` 并刷新 UI，**不重启应用、不影响正在运行的分组**。适用于你手动编辑了配置文件或想刷新备份列表时。

## 8. 备份与恢复

### 8.1 创建备份

仪表盘任何时候改配置前，建议先备份：

![备份管理页](./func_test/05_backup_page.png)

进「备份管理」 → 点右上 **「+ 创建备份」** → 列表顶部立刻出现一条新记录，带时间戳文件名（如 `backup_2026-05-27_11-32-15.json`），底部会闪现提示「备份已创建: <文件名>」。

![创建备份成功提示](./func_test/14_backup_created.png)

### 8.2 备份存哪

备份文件位于：

```
%APPDATA%\com.asd.tauri\backups\
```

每个文件是一个独立的 JSON 配置快照，包含当时所有分组、热键、模式参数。

> ⚠️ **重装系统 / 清理 %APPDATA% 会同时删除所有备份**。建议定期把整个 `backups\` 文件夹拷贝到非系统盘（U 盘、网盘等）。

### 8.3 恢复备份

1. 进「备份管理」→ 找到要恢复的条目。
2. 点该条目右侧的 **「恢复」** 按钮。
3. 弹出确认框「恢复将覆盖当前所有配置，确定继续？」→ 点确定。
4. 当前所有分组配置被该备份的内容替换，**当前正在运行的分组会被停止并重启**。

> ⚠️ 恢复是**覆盖**操作，不可撤销；恢复前建议先「创建一次当前配置的备份」（如果当前配置还有保留价值）。

### 8.4 删除备份

条目右侧的 **「删除」** 按钮。**不可撤销**，但仅删备份文件，不影响当前运行。

### 8.5 自动备份

应用在每次保存分组配置时**自动创建一个备份**（文件名带 `auto` 后缀）。所以即便你忘了手动备份，也能从自动备份里捞回来最近的版本。仪表盘也会显示一个备份计数提示。

## 9. 导入与导出

仪表盘右下有 **「导出全部」** 和 **「导入」** 两个按钮（多选模式时也会出现）。

### 9.1 导出全部

把所有分组配置导出为一个 JSON 文件，弹窗让你选保存位置。文件名建议带日期，便于日后追溯。

> **导出全部 ≠ 创建备份**：备份在 `%APPDATA%` 内，自动管理；导出的 JSON 在你指定的位置，适合跨设备迁移或分享配置。

### 9.2 导入

选一个之前导出的 JSON 文件 → 应用读取 → **追加到当前分组集合**（**不覆盖**）。导入后你可以进「分组编辑」修改 ID 避免冲突，再保存。

## 10. 常见使用场景示例

### 场景 A：游戏里「按住左键持续开火」

1. 仪表盘 → 「+ 添加新分组」。
2. ID = `fire_auto`，名称 = 「自动开火」，热键 = `X`。
3. 模板选 **「长按保持」** → 按键列表 = `LButton`（鼠标左键）。
4. 保存。
5. 在游戏里按住 `X`，左键被持续按住；松开 `X`，左键释放。

### 场景 B：游戏里「一键三连」

1. ID = `combo_3`，名称 = 「三连」，热键 = `F1`。
2. 模板选 **「序列按键」** → 按键 = `q`, `w`, `e`，每步延迟 `100` ms。
3. 保存 → 按 `F1` 自动按 `q` → 100 ms 后按 `w` → 100 ms 后按 `e`。

### 场景 C：日常「一键签到 + 关闭弹窗」

1. ID = `daily_sign`，名称 = 「每日签到」，热键 = `Ctrl+Alt+S`。
2. 模板选 **「序列按键」** → 按键 = `Enter`, `Escape`, `Enter`（签到 → 关闭弹窗 → 确认）。
3. 延迟 `200, 100, 200` ms（给 UI 反应时间）。
4. 保存。

### 场景 D：手柄连发

> 需要先装 vJoy 驱动（详见 §4）。

1. ID = `pad_auto`，名称 = 「手柄 A 键连发」，热键 = `Joy1`（手柄上的某个按钮）。
2. 编辑页「执行模式」选 **「手柄周期」** → 按键 = `Joy1`，间隔 = `50` ms。
3. 保存 → 按下手柄对应键，A 键以每秒 20 次的频率连发。
