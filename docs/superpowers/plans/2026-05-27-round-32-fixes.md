- [ ] **Step 1: 修改 `RegisterHotkey` 按钮注册逻辑**

当前 `RegisterHotkey`（L35-L38）按钮段用 Map 直接覆盖。改为数组嵌套：

```autohotkey
static RegisterHotkey(joyKey, groupId, callback) {
    try {
        if JoystickInput.IsButton(joyKey) {
            key := JoyHotkeyManager._joystickId joyKey
            if !JoyHotkeyManager._registered.Has(key) {
                JoyHotkeyManager._registered[key] := []
                Hotkey(key, (*) => JoyHotkeyManager._OnButtonPress(key), "On")
            }
            for entry in JoyHotkeyManager._registered[key] {
                if entry["groupId"] = groupId
                    return true
            }
            JoyHotkeyManager._registered[key].Push(Map("groupId", groupId, "callback", callback, "joyKey", joyKey))
            return true
        } else if JoystickInput.IsAxis(joyKey) || JoystickInput.IsTrigger(joyKey) {
            JoyHotkeyManager._registered[joyKey] := Map("groupId", groupId, "callback", callback, "joyKey", joyKey)
            JoyHotkeyManager._StartPolling()
            return true
        } else if JoystickInput.IsPov(joyKey) {
            JoyHotkeyManager._registered[joyKey] := Map("groupId", groupId, "callback", callback, "joyKey", joyKey)
            JoyHotkeyManager._StartPolling()
            return true
        }
        return false
    } catch as e {
        ErrorSystem.LogError("JoyHotkeyManager.RegisterHotkey 失败: " e.Message, "ERROR", A_ThisFunc, A_LineNumber)
        return false
    }
}
```

### Task 4: [中等] `_DetectVJoy` 缓存优化

**Files:**
- Modify: `d:\1demo\AutoHotkeydemo\infrastructure\joy_sender.ahk`

- [ ] **Step 1: 移除重复 LoadLibrary/FreeLibrary**

`IsVJoyAvailable()` 已缓存结果（`_vJoyAvailable != -1`），`_DetectVJoy()` 只在首次调用时执行。问题在于检测过程本身每次都 LoadLibrary+FreeLibrary。既然结果已缓存，检测过程只执行一次，DLL 操作开销仅发生在首次。

当前代码：
```autohotkey
static IsVJoyAvailable() {
    if JoySender._vJoyAvailable != -1
        return JoySender._vJoyAvailable
    JoySender._vJoyAvailable := JoySender._DetectVJoy()
    return JoySender._vJoyAvailable
}
```

结果已将 `_vJoyAvailable` 从 `-1` 改为 `true`/`false`，后续调用直接返回缓存值。优化：在 `_DetectVJoy` 中使用 `LoadLibrary` 后不立即 `FreeLibrary`，保持模块句柄以备后续 vJoy 操作使用。

```autohotkey
static _DetectVJoy() {
    try {
        hModule := DllCall("LoadLibrary", "Str", "vJoyInterface.dll", "Ptr")
        if hModule {
            JoySender._vJoyDll := "vJoyInterface.dll"
            return true
        }
    } catch {
    }
    try {
        hModule := DllCall("LoadLibrary", "Str", A_WinDir "\System32\vJoyInterface.dll", "Ptr")
        if hModule {
            JoySender._vJoyDll := A_WinDir "\System32\vJoyInterface.dll"
            return true
        }
    } catch {
    }
    return false
}
```
